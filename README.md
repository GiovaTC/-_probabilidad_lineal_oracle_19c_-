Probabilidad y función lineal con Java 21, IntelliJ IDEA y Oracle 19c
Aplicación de escritorio educativa que calcula una probabilidad clásica, utiliza tres niveles de condicionales if,
dibuja la función lineal f(x) = mx + b mediante Java Swing y guarda los resultados en Oracle Database 19c usando JDBC.
Nota matemática: la función lineal se utiliza como una representación gráfica asociada a la probabilidad calculada.
No significa que todas las probabilidades sean funciones lineales.

1. Funcionalidades
- Entrada de casos favorables y casos posibles.
- Validación de datos.
- Cálculo de P(A) = casos favorables / casos posibles.
- Presentación de la probabilidad como decimal y porcentaje.
- Clasificación didáctica:
  - P = 0: evento imposible.
  - 0 < P < 0.5: probabilidad baja.
  - P >= 0.5: probabilidad media/alta.
- Interfaz gráfica con Swing.
- Gráfica de f(x) = mx + b, donde m es la probabilidad decimal y b es el intercepto ingresado.
- Persistencia de datos en Oracle 19c .

2. Requisitos
- JDK 21.
- IntelliJ IDEA.
- Maven (integrado en IntelliJ).
- Oracle Database 19c y SQL Developer o SQL*Plus.
- Usuario de Oracle con permisos para crear tablas e insertar registros .

CREATE TABLE calculos_probabilidad (
    id                NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    casos_favorables  NUMBER(12) NOT NULL,
    casos_posibles    NUMBER(12) NOT NULL,
    probabilidad      NUMBER(12,8) NOT NULL,
    clasificacion     VARCHAR2(40) NOT NULL,
    pendiente         NUMBER(12,8) NOT NULL,
    intercepto        NUMBER(12,8) NOT NULL,
    fecha_registro    TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,

    CONSTRAINT chk_casos_favorables
        CHECK (casos_favorables >= 0),
    CONSTRAINT chk_casos_posibles
        CHECK (casos_posibles > 0),
    CONSTRAINT chk_favorables_menor
        CHECK (casos_favorables <= casos_posibles),
    CONSTRAINT chk_probabilidad
        CHECK (probabilidad BETWEEN 0 AND 1)
);

4.4 src/main/java/com/giovany/probabilidad/dao/ProbabilidadDAO.java
Esta clase inserta el cálculo en Oracle mediante PreparedStatement.
package com.giovany.probabilidad.dao;

import com.giovany.probabilidad.config.ConexionOracle;

import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.SQLException;

public class ProbabilidadDAO {

    public void guardar(
            long favorables,
            long posibles,
            double probabilidad,
            String clasificacion,
            double pendiente,
            double intercepto
    ) throws SQLException {

        String sql = """
                INSERT INTO calculos_probabilidad
                (casos_favorables, casos_posibles, probabilidad,
                 clasificacion, pendiente, intercepto)
                VALUES (?, ?, ?, ?, ?, ?)
                """;

        try (Connection cn = ConexionOracle.obtenerConexion();
             PreparedStatement ps = cn.prepareStatement(sql)) {

            ps.setLong(1, favorables);
            ps.setLong(2, posibles);
            ps.setDouble(3, probabilidad);
            ps.setString(4, clasificacion);
            ps.setDouble(5, pendiente);
            ps.setDouble(6, intercepto);

            ps.executeUpdate();
        }
    }
}

4.5 src/main/java/com/giovany/probabilidad/ui/GraficaLinealPanel.java
Esta clase dibuja los ejes y la recta con Java2D.
package com.giovany.probabilidad.ui;

import javax.swing.JPanel;
import java.awt.BasicStroke;
import java.awt.Color;
import java.awt.Font;
import java.awt.Graphics;
import java.awt.Graphics2D;
import java.awt.RenderingHints;

public class GraficaLinealPanel extends JPanel {

    private double pendiente = 0.3;
    private double intercepto = 0.0;

    public GraficaLinealPanel() {
        setBackground(Color.WHITE);
        setPreferredSize(new java.awt.Dimension(600, 360));
    }

    public void actualizarFuncion(double m, double b) {
        pendiente = m;
        intercepto = b;
        repaint();
    }

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);

        Graphics2D g2 = (Graphics2D) g.create();
        g2.setRenderingHint(
                RenderingHints.KEY_ANTIALIASING,
                RenderingHints.VALUE_ANTIALIAS_ON
        );

        int left = 58;
        int right = 25;
        int top = 35;
        int bottom = 48;

        int w = getWidth() - left - right;
        int h = getHeight() - top - bottom;

        if (w <= 0 || h <= 0) {
            g2.dispose();
            return;
        }

        // Dominio horizontal: x desde 0 hasta 10.
        double xMin = 0;
        double xMax = 10;

        double y1 = pendiente * xMin + intercepto;
        double y2 = pendiente * xMax + intercepto;

        double yMin = Math.min(0, Math.min(y1, y2));
        double yMax = Math.max(1, Math.max(y1, y2));

        if (Math.abs(yMax - yMin) < 1e-9) {
            yMax = yMin + 1;
        }

        double pad = (yMax - yMin) * 0.12;
        yMin -= pad;
        yMax += pad;

        g2.setFont(new Font("SansSerif", Font.PLAIN, 11));
        g2.setColor(new Color(225, 225, 225));

        // Cuadrícula y etiquetas de los ejes.
        for (int i = 0; i <= 10; i++) {
            int x = left + i * w / 10;
            int y = top + h - i * h / 10;

            g2.drawLine(x, top, x, top + h);
            g2.drawLine(left, y, left + w, y);

            double yVal = yMin + (yMax - yMin) * i / 10.0;

            g2.setColor(Color.DARK_GRAY);
            g2.drawString(String.format("%.2f", yVal), 5, y + 4);
            g2.drawString(Integer.toString(i), x - 3, top + h + 18);

            g2.setColor(new Color(225, 225, 225));
        }

        // Ejes.
        g2.setColor(Color.DARK_GRAY);
        g2.drawLine(left, top + h, left + w, top + h);
        g2.drawLine(left, top, left, top + h);

        // Títulos.
        g2.setFont(new Font("SansSerif", Font.BOLD, 13));
        g2.drawString(
                String.format("f(x) = %.4f x + %.4f", pendiente, intercepto),
                left,
                20
        );
        g2.drawString("x", left + w / 2, getHeight() - 10);
        g2.drawString("f(x)", 10, top - 8);

        // Recta que representa f(x) = mx + b.
        int px1 = left;
        int py1 = mapY(pendiente * xMin + intercepto, yMin, yMax, top, h);
        int px2 = left + w;
        int py2 = mapY(pendiente * xMax + intercepto, yMin, yMax, top, h);

        g2.setColor(new Color(30, 110, 210));
        g2.setStroke(new BasicStroke(3f));
        g2.drawLine(px1, py1, px2, py2);

        g2.dispose();
    }

    private int mapY(
            double value,
            double yMin,
            double yMax,
            int top,
            int h
    ) {
        return top + h
                - (int) Math.round(
                    (value - yMin) / (yMax - yMin) * h
                );
    }
}

4.6 src/main/java/com/giovany/probabilidad/Main.java
Esta es la clase principal: construye la ventana, valida los datos, calcula la probabilidad,
ejecuta los tres niveles de condicionales y solicita el guardado en Oracle .
package com.giovany.probabilidad;

import com.giovany.probabilidad.dao.ProbabilidadDAO;
import com.giovany.probabilidad.ui.GraficaLinealPanel;

import javax.swing.*;
import java.awt.*;
import java.sql.SQLException;

public class Main extends JFrame {

    private final JTextField txtFavorables = new JTextField("3", 10);
    private final JTextField txtPosibles = new JTextField("10", 10);
    private final JTextField txtIntercepto = new JTextField("0", 10);

    private final JLabel lblResultado =
            new JLabel("Ingresa los datos y pulsa el botón.");

    private final GraficaLinealPanel grafica = new GraficaLinealPanel();
    private final ProbabilidadDAO dao = new ProbabilidadDAO();

    public Main() {
        setTitle("Probabilidad y función lineal - Oracle 19c");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(900, 580);
        setLocationRelativeTo(null);
        construirInterfaz();
    }

    private void construirInterfaz() {
        JPanel formulario = new JPanel(new GridBagLayout());
        formulario.setBorder(
                BorderFactory.createTitledBorder("Datos de entrada")
        );

        GridBagConstraints c = new GridBagConstraints();
        c.insets = new Insets(6, 8, 6, 8);
        c.anchor = GridBagConstraints.WEST;

        agregarCampo(
                formulario, c, 0, "Casos favorables:", txtFavorables
        );
        agregarCampo(
                formulario, c, 1, "Casos posibles:", txtPosibles
        );
        agregarCampo(
                formulario, c, 2, "Intercepto b:", txtIntercepto
        );

        JButton btnCalcular =
                new JButton("Calcular, graficar y guardar");
        btnCalcular.addActionListener(e -> calcular());

        c.gridx = 0;
        c.gridy = 3;
        c.gridwidth = 2;
        c.fill = GridBagConstraints.HORIZONTAL;
        formulario.add(btnCalcular, c);

        JPanel panelResultado = new JPanel(new BorderLayout(8, 8));
        panelResultado.setBorder(
                BorderFactory.createTitledBorder("Resultado")
        );

        lblResultado.setVerticalAlignment(SwingConstants.TOP);
        lblResultado.setFont(new Font("SansSerif", Font.PLAIN, 14));
        panelResultado.add(lblResultado, BorderLayout.CENTER);

        JPanel izquierda = new JPanel(new BorderLayout(8, 8));
        izquierda.setPreferredSize(new Dimension(285, 500));
        izquierda.add(formulario, BorderLayout.NORTH);
        izquierda.add(panelResultado, BorderLayout.CENTER);

        setLayout(new BorderLayout(10, 10));
        add(izquierda, BorderLayout.WEST);
        add(grafica, BorderLayout.CENTER);

        ((JComponent) getContentPane()).setBorder(
                BorderFactory.createEmptyBorder(10, 10, 10, 10)
        );
    }

    private void agregarCampo(
            JPanel panel,
            GridBagConstraints c,
            int fila,
            String etiqueta,
            JTextField campo
    ) {
        c.gridwidth = 1;
        c.fill = GridBagConstraints.NONE;

        c.gridx = 0;
        c.gridy = fila;
        panel.add(new JLabel(etiqueta), c);

        c.gridx = 1;
        panel.add(campo, c);
    }

    private void calcular() {
        try {
            long favorables =
                    Long.parseLong(txtFavorables.getText().trim());

            long posibles =
                    Long.parseLong(txtPosibles.getText().trim());

            double intercepto =
                    Double.parseDouble(txtIntercepto.getText().trim());

            String clasificacion;

            /*
             * Tres niveles de condicionales:
             * 1. Verificar que los casos posibles sean mayores que cero.
             * 2. Verificar que los casos favorables estén en el rango.
             * 3. Clasificar la probabilidad calculada.
             */
            if (posibles > 0) {

                if (favorables >= 0 && favorables <= posibles) {

                    double probabilidad =
                            (double) favorables / posibles;

                    if (probabilidad == 0.0) {
                        clasificacion = "Evento imposible";
                    } else if (probabilidad < 0.5) {
                        clasificacion = "Probabilidad baja";
                    } else {
                        clasificacion = "Probabilidad media/alta";
                    }

                    grafica.actualizarFuncion(
                            probabilidad,
                            intercepto
                    );

                    lblResultado.setText(
                            "<html>"
                            + "<b>Probabilidad:</b> "
                            + String.format("%.4f", probabilidad)
                            + "<br>"
                            + "<b>Porcentaje:</b> "
                            + String.format(
                                    "%.2f%%", probabilidad * 100
                            )
                            + "<br>"
                            + "<b>Clasificación:</b> "
                            + clasificacion
                            + "<br>"
                            + "<b>Función:</b> f(x) = "
                            + String.format("%.4f", probabilidad)
                            + "x + "
                            + String.format("%.4f", intercepto)
                            + "<br><br>"
                            + "Guardando resultado en Oracle 19c..."
                            + "</html>"
                    );

                    try {
                        dao.guardar(
                                favorables,
                                posibles,
                                probabilidad,
                                clasificacion,
                                probabilidad,
                                intercepto
                        );

                        lblResultado.setText(
                                lblResultado.getText().replace(
                                    "Guardando resultado en Oracle 19c...",
                                    "Registro guardado en Oracle 19c."
                                )
                        );

                    } catch (SQLException ex) {
                        JOptionPane.showMessageDialog(
                                this,
                                "El cálculo se realizó, pero no se pudo "
                                + "guardar en Oracle. Verifica la conexión, "
                                + "el servicio y la tabla.\n\n"
                                + ex.getMessage(),
                                "Error de base de datos",
                                JOptionPane.ERROR_MESSAGE
                        );
                    }

                } else {
                    mostrarError(
                            "Los casos favorables deben estar entre "
                            + "0 y los casos posibles."
                    );
                }

            } else {
                mostrarError(
                        "Los casos posibles deben ser mayores que cero."
                );
            }

        } catch (NumberFormatException ex) {
            mostrarError(
                    "Ingresa números enteros para los casos y un número "
                    + "válido para el intercepto."
            );
        }
    }

    private void mostrarError(String mensaje) {
        JOptionPane.showMessageDialog(
                this,
                mensaje,
                "Datos inválidos",
                JOptionPane.WARNING_MESSAGE
        );
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(
                () -> new Main().setVisible(true)
        );
    }
}

9. Errores comunes
- ORA-12514 / ORA-12505: verifica el service name o SID y el listener.
- ORA-01017: comprueba usuario y contraseña.
- ORA-00942: ejecuta el script de creación de tabla en el esquema correcto.
- No se encuentra el driver JDBC: confirma que Maven haya importado las dependencias y que el proyecto esté sincronizado.
- El cálculo aparece pero no se guarda: revisa el mensaje de error de conexión, los permisos y que la tabla exista.

10. Consideraciones
- Los casos favorables y posibles se reciben como números enteros.
- Los casos posibles deben ser mayores que cero.
- Los casos favorables no pueden ser negativos ni superar los posibles.
- La pendiente de la función es la probabilidad expresada como decimal.
- El intercepto b puede ser cualquier valor numérico.
- La clasificación es una regla didáctica y se puede modificar.
- En un entorno productivo, evita credenciales incrustadas en el código y agrega manejo de configuración y registros de errores .
